# TAVREN — Beauty Studio Demo Website

TAVREN is a fully fictional beauty studio brand created as a commercial web development demo project.

The website demonstrates how a modern beauty business can combine services, pricing, specialists, portfolio work and appointment booking into one digital experience.

## Live Demo

https://setyann.github.io/TAVREN/

## About the Project

TAVREN was designed as an upper-middle / accessible premium beauty studio based in Yerevan, Armenia.

The project focuses on reducing the friction between discovering a beauty service and booking an appointment.

The main customer flow is:

**Discover → Service → Price → Result → Master → Location → Date → Time → Booking**

This is not a real business or client project.

All names, services, masters, locations, prices, reviews, schedules and other company information are fictional and were created exclusively for demonstration purposes.

## Booking Flow

The booking interface follows this structure:

```text
Service
↓
Master
↓
Location
↓
Date
↓
Time
↓
Client Details
↓
Confirmation
```

Available options depend on:

* selected service;
* master specialization;
* master working schedule;
* studio location;
* service duration;
* available demo time slots.

The booking system is implemented entirely on the front end and does not submit appointments to a real business.

## Design Direction

TAVREN uses a warm editorial visual style rather than a traditional pink or luxury beauty aesthetic.

The design system combines:

* warm neutral backgrounds;
* dark typography;
* muted terracotta accents;
* editorial imagery;
* restrained borders and radius;
* DM Serif Display;
* Manrope.

The interface was designed independently for this project and is not based on a pre-existing website template.
